About AI Chatbot

AI Chatbot is a standalone web application designed for interactive learning in computer science.

⚙️ Technology & Architecture

  • Backend: Python Flask REST API (/api/chat)
  • Engine: Context-aware rule-based pattern matching in chatbot.py
  • Multi-turn Dialogue: Supports natural follow-ups like "Explain more", "Give an example", "Why?", and "Compare them".
  • Frontend: Semantic HTML5, responsive CSS3, and Vanilla JavaScript
  • Storage: Multi-conversation history and context persisted via localStorage

🎯 Supported Knowledge Topics

  • Artificial Intelligence: Narrow vs. General AI, NLP, Computer Vision, Generative AI
  • Machine Learning: Supervised, Unsupervised, Reinforcement Learning, Neural Networks
  • Programming: Variables, Loops, Functions, Conditionals, Data Structures, OOP, Debugging
  • Conversational: Greetings, Bot Identity, Capabilities, Thanks, Goodbye, Help

✨ Interactive Features

  • Copy Response: Click the copy button to copy any bot message to clipboard with instant confirmation.
  • Regenerate Response: Click regenerate to re-process the prompt with current context.
  • Feedback: Thumbs-up and thumbs-down buttons to rate responses.
  • Smart Follow-up Suggestions: 2–3 contextual suggestion chips following every response.

⌨️ Keyboard Shortcuts

  • Enter: Send message
  • Shift + Enter: Insert new line
  • Esc: Close modal / mobile sidebar
